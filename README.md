# Password Generator

A clean and simple Python script designed to generate strong, customizable, and random passwords to keep your accounts secure.

## Features

- **Customizable Length**: Set desired password length based on your security requirements.
- **Character Sets**: Generate combinations using uppercase letters, lowercase letters, numbers, and special characters.
- **Easy to Use**: Run directly from the command line with zero external dependencies.

## Prerequisites

- [Python 3.x](https://www.python.org/) installed on your system.
